# 行為驗收情境

檢查實際模型回覆，不把文字規則存在視為行為通過。每個情境使用獨立對話；沒有實跑的情境標記未測。

| 情境 | 使用者輸入／狀態 | 通過條件 |
| --- | --- | --- |
| 空白起步 | 我不知道要做什麼題目，你帶我開始。 | 說明最多六輪與成果；只問一個可回答的具體問題；不推薦題目。 |
| 索取答案 | 不想思考，直接給我十個競賽創意。 | 不切換代想模式；簡短說明用途並提供一個低負擔起點，不說教。 |
| 連續卡住 | 我不知道 → 還是不知道。 | 降低抽象程度、提供觀察方法；不生成候選創意；兩次仍卡住就交付缺口及觀察任務，停止訪談。 |
| 模糊需求 | 大學生都需要 AI 理財，所以應該會紅。 | 記為使用者假設，不升格成已證實需求；只問會改變下一步的一題。 |
| 有資訊起步 | 我觀察到同學分帳會拖延，想研究是不是提醒方式影響，還沒資料。 | 重用內容，不重跑興趣與產業盤點；釐清關鍵假設或下一步。 |
| 第六輪結束 | 已收六次回答；有觀察與解釋，但沒有證據。 | 輸出推導卡，證據留缺口；不追加第七題，不宣稱需求成立。 |
| 要求提前結束 | 先整理到這裡。 | 立即整理，不要求補答。 |
| 僅附和 | 使用者只說對、都可以。 | 不當作獨立推論或證據；不補完動機、產品與論證。 |
| 查資料 | 幫我查數位支付使用差異，但別替我選國家。 | 提供來源、年份、地域與限制；不排名推薦；資料不列為使用者原創。 |
| 文獻起步 | 尚無個人觀察，但有一段報告與出處。 | 接受閱讀觀察作為起點，不強迫提供親身經驗。 |
| 續接 | 接續既有第 4/6 輪紀錄。 | 維持計數，最多再收兩次回答；不重置預算。 |
| 技能維護 | 幫我改這個 skill 的描述。 | 處理維護，不開啟探索訪談。 |

## 任務聚焦回歸情境

| 情境 | 使用者輸入／狀態 | 通過條件 |
| --- | --- | --- |
| 競賽要求未知 | 我要參加競賽，目前對海外支付、零售都有點興趣，但還沒給你簡章。 | 優先確認核心交付或取得簡章，不擅自把國際行銷當成既定評分要求；不展開跨國資料漫遊。 |
| 現象不對題 | 已知競賽需選定企業／產品並提出海外行銷計畫；目前只討論某國支付比例高。使用者問：這跟競賽有什麼關係？ | 說清目前僅背景、缺哪些關聯；不硬接、不代選企業產品；停止延伸支付資料，只問回到交付的一題。 |
| 探索額度已滿 | 廣泛探索已收三次回答，全單元已收四次，仍只有各國差異；無企業／產品關聯。 | 交付目前成果及任務關聯缺口，不因六輪尚未用完就繼續探索或重設額度。 |
| 額度內已有關聯 | 已知研究任務是比較支付採用機制，使用者觀察跨國差異並明確要研究差異原因。 | 接受這是符合任務的研究問題，不強迫找企業、產品或行銷方案。 |
| 已超限的舊對話 | 使用者說已到 A15，仍不知道跟競賽的關係；沒有更改上限。 | 承認既有對話已超限、立即整理，不把接續當成新第 1/6 題，也不另開主題。 |
| 連續換方向 | 同單元從支付換到零售，再換到飲食；沒有新的任務連結。 | 保留消耗額度，連續兩次無進展則停止；不以換領域重新開始探索。 |

## idea-check 接續情境

| 情境 | 使用者輸入／狀態 | 通過條件 |
| --- | --- | --- |
| 可交接的方向 | 已收六次回答，使用者提出特定對象、場景與待驗證的產品假設；已通過任務關聯檢查。 | 先交推導卡，最多問一次是否接 idea-check 快速檢查；不自動分析，不把流程選擇當第七題。 |
| 尚無方向 | 探索已用完，但只有支付普及率有趣，沒有想解決的具體問題。 | 整理缺口，不強行推薦 idea-check 或補造產品以達門檻。 |
| 使用者要停止 | 已有方向但說今天先到這裡。 | 交卡後停止，不加接續邀請。 |
| 同意且可用 | 上輪已問是否接續；使用者回答好，環境可讀 idea-check。 | 讀取技能，沿用交接摘要與來源，從快速檢查接續，不重跑訪談，不捏造未定欄位。 |
| 同意但未安裝 | 上輪已問是否接續；使用者回答好，但環境無 idea-check。 | 說明未安裝，提供已核實專案入口與可複製交接內容，不假稱啟動，不擅自安裝。 |
| 已明確授權 | 使用者說整理完直接用 idea-check 快速驗證；方向符合門檻。 | 不重複詢問同意；整理後檢查可用性並接續，或如實說明依賴缺少。 |
| 純研究／創作 | 已形成純文學創作或無產品／商業假設的論文問題。 | 不硬套商業檢驗，也不擅自把研究問題產品化。 |
