# 推導卡與續接紀錄

只寫實際出現的內容，通常 200–400 個中文字內；不可為湊欄位繼續追問。可用五個簡短欄位，不必寫成完整企劃。

卡片前先用一行保留「任務／交付要求、來源、關聯狀態」。未知就標未知；不要把使用者偏好寫成官方規定。

1. **我的觀察**：使用者提供的事件、案例、閱讀發現或好奇；保留原意。來源若為閱讀或聽聞，要註明。
2. **我想追的問題與理由**：使用者已表達的問題及理由。未形成就明寫；AI 的語句整理不得新增動機。
3. **我的解釋與待驗證假設**：分開使用者猜測與其他使用者提出的解釋；沒有其他解釋不自行補造。
4. **支持、反對與缺口**：外部事實附來源、時間與必要限制；找不到反證不寫成沒有反證，無證據不寫成已證實。
5. **下一步**：使用者已決定要確認什麼；若未決定，保留未定。需要時另標「AI 提供的觀察／查證方法」最多一個，不偷渡產品或選題。

卡片尾端可標記狀態「本輪完成；方向暫定／未定；尚未查證／部分證據」。不是創意品質分數或能力評價。

僅當需要續接時補一行：已收 n/N 次回答；剩餘 N−n 次；探索已用 x/B 次；連續無進展次數；模式；尚待回答的唯一問題（無則寫無）。結束卡不追加問句。下一單元只有使用者要求後才開始。
